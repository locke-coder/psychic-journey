# D03 UI/UX 패치 노트

## 목적

D03 패치는 계산 산식은 유지하고, 화면의 기능 중복과 표시 라벨 분산을 줄이는 데 집중했다. 사용자는 첫 화면의 `월마감 상태판`에서 목표 상태, 월마감 예상 실적, 목표 대비 차이, 다음 마감 누적선 필요실적, 운영모드, 추천 전략을 한 번에 확인한다.

## 주요 변경

- `src/display_labels.py`를 추가해 목표 상태, 핵심 지표명, P/O/N 전략명, 전략군, 운영모드 라벨을 단일 관리한다.
- 홈 화면의 `Next Action Panel` 반복 노출을 줄이고, 오늘 판단 카드는 유지했다.
- KPI 카드는 현재 누적 실적, 월마감 예상 실적, 목표 대비 차이, 다음 마감 누적선 필요실적, 추천 전략 중심으로 압축했다.
- 시나리오 화면에는 `운영 판단판`을 추가했다. 원본 ScenarioGrid는 접힌 영역에서 확인하고, 기본 표는 한국어 전략명과 전략군을 우선 표시한다.
- Excel 공유 화면에는 최신 daily_report 파일명, 생성/수정시각, 크기를 표시하는 freshness badge를 추가했다.
- 사이드바와 검증·운영관리 페이지에 Public Streamlit/외부 공개 URL 실데이터 업로드 금지 문구를 추가했다.

## 유지한 원칙

- 마감일 판단은 계속 `is_close_day` 입력값만 사용한다.
- `day_name`은 표시용이며 마감일 추론에 사용하지 않는다.
- F1/F2/F3, P1/P2/P3, O1/O2/O3 계산 산식과 ScenarioGrid 9행 구조는 변경하지 않았다.
- `.streamlit/secrets.toml` 내용은 읽거나 출력하지 않는다.
